# Taste Skill (Modifier)

## Micro-Aesthetics

- **Typography:** Ensure `Inter` is used with tight tracking on headings and 1.5 line height on body.
- **Spacing:** strictly adhere to the 4px grid. Increase whitespace around primary CTAs.
- **Visual Hierarchy:** Use muted text colors (`text-muted-foreground`) for secondary information to make primary data pop.
- **Constraint:** This skill supplements, but NEVER overrides, the Project Design System.
