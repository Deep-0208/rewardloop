# RewardLoop Enterprise Project Handbook

Welcome to the definitive source of truth for RewardLoop. This handbook consolidates all Engineering, Design, Security, and AI Standards necessary to build a world-class SaaS PWA.

## Guiding Vision

- **Mobile-first PWA:** Optimized for fast, one-handed usage at 360px viewports.
- **Billing First:** The core loop of RewardLoop is transaction speed.
- **Enterprise Reliability:** Built on Next.js, Supabase, and strict TypeScript.
